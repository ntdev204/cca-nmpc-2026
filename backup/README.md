# Paper snapshot policy

Exactly one paper snapshot is active in this repository workspace:

`backup/paper-current-2026-08-01/`

The snapshot contains 12 files, including `SNAPSHOT.md`, the retained PDF, source,
bibliography, generated results, and figures. It is a historical reference only.

Rules:

- Do not edit, regenerate, move, rename, or partially replace anything inside the active
  snapshot.
- Do not use values or figures from the snapshot as evidence for the redesigned study.
- Do not commit the snapshot; `.gitignore` excludes all backup payloads and retains only
  this policy file.
- Do not create a second active snapshot. A replacement requires explicit approval, a
  complete hash inventory, and an atomic handover that leaves exactly one active path.
- Continue manuscript authoring and PDF builds only on Overleaf. A backup is never a
  local authoring tree.
