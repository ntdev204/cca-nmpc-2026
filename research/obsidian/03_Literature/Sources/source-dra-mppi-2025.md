# Dynamic risk-aware MPPI (2025)

## Primary record

- **Title:** *Dynamic Risk-Aware MPPI for Mobile Robots in Crowds via Efficient Monte Carlo Approximations*
- **Record:** [arXiv:2506.21205](https://arxiv.org/abs/2506.21205)
- **Screened:** 2026-08-13, Google/web discovery followed by the arXiv record

## What is established

The preprint describes dynamic risk-aware MPPI for uncertain moving obstacles,
using sample-based collision-risk handling and comparisons with sampling and
scenario-based planners. It is a direct boundary for the user's requested
MPPI benchmark family.

## Boundary for this project

It is a preprint and has not been admitted to the Zotero focused set in this
session. The method is not evidence that a fixed-budget context allocator is
new, and its platform, sensing and timing assumptions require full-text
extraction before any numerical comparison.

## Consequence

The benchmark plan should retain MPPI as a comparator when a fair implementation
and equal compute budget are possible. If it cannot be reproduced fairly, the
omission and its computational reason must be recorded rather than replaced by
a weaker controller.
