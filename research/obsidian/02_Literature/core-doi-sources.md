# Core DOI sources

This is a focused, non-exhaustive registry. Inclusion records a source needed to
bound a claim; it does not imply that the search is systematic or complete.

## Closest architecture and human-aware navigation

- Stefanini et al., *Efficient Context-Aware Model Predictive Control for
  Human-Aware Navigation*. DOI:
  [10.1109/LRA.2024.3461552](https://doi.org/10.1109/LRA.2024.3461552).
- Samavi et al., *SICNav: Safe and Interactive Crowd Navigation Using Model
  Predictive Control and Bilevel Optimization*. DOI:
  [10.1109/TRO.2024.3484634](https://doi.org/10.1109/TRO.2024.3484634).
- *SICNav-Diffusion: Safe and Interactive Crowd Navigation With Diffusion
  Trajectory Predictions*. DOI:
  [10.1109/LRA.2025.3585713](https://doi.org/10.1109/LRA.2025.3585713).
- Brito et al., *Where to Go Next: Learning a Subgoal Recommendation Policy for
  Navigation in Dynamic Environments*. DOI:
  [10.1109/LRA.2021.3068662](https://doi.org/10.1109/LRA.2021.3068662).
- Wang et al., *Autonomous Navigation of Mobile Robots: A Hierarchical
  Planning--Control Framework with Integrated DWA and MPC*. DWA converts a
  global path and sensed local environment into a local path that an MPC layer
  tracks, with simulation and robot experiments. DOI:
  [10.3390/s25072014](https://doi.org/10.3390/s25072014).
- Zhang et al., *Robot Navigation With Reinforcement Learned Path Generation
  and Fine-Tuned Motion Control*. A learned path generator is separated from a
  motion fine-tuning module and evaluated in simulation and hardware. DOI:
  [10.1109/LRA.2023.3284354](https://doi.org/10.1109/LRA.2023.3284354).
- Imad et al., *Deep Learning-Based NMPC for Local Motion Planning of Last-Mile
  Delivery Robot*. Learned drivable space, robot state and a global plan enter
  an NMPC local planner that produces commands. DOI:
  [10.3390/s22218101](https://doi.org/10.3390/s22218101).
- Singamaneni et al., *Human-Aware Navigation Planner for Diverse Human--Robot
  Interaction Contexts*. It demonstrates tunable context-dependent planning in
  simulation and on a robot. DOI:
  [10.1109/IROS51168.2021.9636613](https://doi.org/10.1109/IROS51168.2021.9636613).
- Eirale et al., *Learning Social Cost Functions for Human-Aware Path Planning*.
  DOI: [10.1109/IROS58592.2024.10802768](https://doi.org/10.1109/IROS58592.2024.10802768).
- *Crowd Navigation in a Multi-Room Environment: A Model Predictive Control
  Framework for Mobile Robots*. DOI:
  [10.3389/frobt.2026.1812386](https://doi.org/10.3389/frobt.2026.1812386).
- Oleinikov et al., *Scenario-Based Model Predictive Control with Probabilistic
  Human Predictions for Human--Robot Coexistence*. Scenario-tree NMPC,
  recursive-feasibility/stability analysis and human-interaction experiments.
  DOI:
  [10.1016/j.conengprac.2023.105769](https://doi.org/10.1016/j.conengprac.2023.105769).
- Nurbayeva and Rubagotti, *Nonlinear Model Predictive Control with Set Terminal
  Constraint for Safe Robot Motion Planning via Speed and Separation
  Monitoring*. Point/set-terminal NMPC with formal results under a static-human
  assumption. DOI:
  [10.1016/j.conengprac.2024.106155](https://doi.org/10.1016/j.conengprac.2024.106155).
- Li et al., *Design of a Model Predictive Planner for a Tethered Guide Robot
  Considering Human--Robot Interaction*. The interaction model is calibrated
  with participant experiments. DOI:
  [10.1016/j.ejcon.2026.101572](https://doi.org/10.1016/j.ejcon.2026.101572).

## Evolutionary, context-aware, and people-aware planning

- Guo et al., *Local Path Planning of Mobile Robot Based on Long Short-Term
  Memory Neural Network*. LSTM is trained from fuzzy-controller samples for a
  mobile-robot local-planning task. DOI:
  [10.3103/S014641162101003X](https://doi.org/10.3103/S014641162101003X).
- Guo et al., *A Fusion Method of Local Path Planning for Mobile Robots Based
  on LSTM Neural Network and Reinforcement Learning*. It combines LSTM, fuzzy
  control, and reinforcement learning for local planning. DOI:
  [10.1155/2021/5524232](https://doi.org/10.1155/2021/5524232).
- Molina-Leal et al., *Trajectory Planning for a Mobile Robot in a Dynamic
  Environment Using an LSTM Neural Network*. The network maps LiDAR, robot,
  and goal inputs to linear and angular velocity in simulation. DOI:
  [10.3390/app112210689](https://doi.org/10.3390/app112210689).
- Wang et al., *UbiPaPaGo: Context-Aware Path Planning*. It combines a spatial
  conceptual map with GA for human-centered context-aware path selection; it is
  not a mobile-robot controller study. DOI:
  [10.1016/j.eswa.2010.09.077](https://doi.org/10.1016/j.eswa.2010.09.077).
- Bacchin et al., *Learning to Plan People-Aware Trajectories for Robot
  Navigation: A Genetic Algorithm*. GA trains a ROS navigation stack under
  moving-person disturbances and proxemic objectives in Gazebo. DOI:
  [10.1109/ECMR50962.2021.9568804](https://doi.org/10.1109/ECMR50962.2021.9568804).
- Sampathkumar et al., *Optimization of Artificial Potential Field Using
  Genetic Algorithm for Human-Aware Navigation of Autonomous Mobile Robots*.
  GA tunes a human-aware artificial-potential-field formulation. DOI:
  [10.1007/978-3-031-46778-3_15](https://doi.org/10.1007/978-3-031-46778-3_15).
- Bakdi et al., *Optimal Path Planning and Execution for Mobile Robots Using
  Genetic Algorithm and Adaptive Fuzzy-Logic Control*. It combines GA, PCHIP,
  explicit geometry, tracking control, sensor fusion, and physical execution.
  DOI:
  [10.1016/j.robot.2016.12.008](https://doi.org/10.1016/j.robot.2016.12.008).
- *Graphics Processing Unit-Enabled Path Planning Based on Global Evolutionary
  Dynamic Programming and Local Genetic Algorithm Optimization*. It reports
  dynamic-environment local GA refinement on an edge robot at approximately
  0.1 s per path. DOI:
  [10.1016/j.asoc.2025.113167](https://doi.org/10.1016/j.asoc.2025.113167).
- Rodriguez Ramirez et al., *Nonlinear MBPC for Mobile Robot Navigation Using
  Genetic Algorithms*. GA performs online nonlinear optimization inside the
  predictive controller, rather than generating a reference for a separate
  NMPC layer. DOI:
  [10.1109/ROBOT.1999.770473](https://doi.org/10.1109/ROBOT.1999.770473).
- Song and Huh, *Driving and Steering Collision Avoidance System of Autonomous
  Vehicle with Model Predictive Control Based on Non-Convex Optimization*.
  A risk supervisor and micro-GA solve a nonconvex MPC collision-avoidance
  problem. DOI:
  [10.1177/16878140211027669](https://doi.org/10.1177/16878140211027669).
- Kim et al., *Development of Local Path Planning Using Selective Model
  Predictive Control, Potential Fields, and Particle Swarm Optimization*.
  Population search and selective MPC are evaluated on a Jetson-equipped AGV.
  DOI: [10.3390/robotics13030046](https://doi.org/10.3390/robotics13030046).
- Nam and Kim, *MPPI-Based Integrated Task Assignment, Path Planning, and
  Control for Unmanned Ground Vehicles*. GA and MPPI are integrated across
  planning and control. DOI:
  [10.1007/s12555-024-0543-7](https://doi.org/10.1007/s12555-024-0543-7).
- Li et al., *Model Predictive Control for the Tracking of Autonomous Mobile
  Robot Combined with a Local Path Planning*. An APF local planner is composed
  with tracking control and explicit MPC. DOI:
  [10.1177/00202940211043070](https://doi.org/10.1177/00202940211043070).
